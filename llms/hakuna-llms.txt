# hakuna

> hakuna AG is a Swiss digital time-tracking and personnel-management platform for SMEs, covering time recording, absences, projects, tasks, clients, and workforce administration. It exposes a token-authenticated JSON REST API at app.hakuna.ch/api/v1. This llms.txt was generated by the API Evangelist enrichment pipeline from the published API documentation.

## API

- [hakuna Time Tracking API docs](https://app.hakuna.ch/api_docs): REST API reference — auth (X-Auth-Token), timer, time entries, absences, projects, tasks, users, management endpoints, 100 req/min rate limit.
